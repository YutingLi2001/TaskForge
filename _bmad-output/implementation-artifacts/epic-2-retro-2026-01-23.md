## Challenges & Learnings

### Delete Operation Complexity (Story 2.4)
- **Issue:** Story 2.4 required multiple review iterations with fixes for:
  - Async delete handler
  - Delete loading state
  - Delete-twice 404 test
  - Preventing delete re-entry during confirmation
  - Disabling edit during delete
- **Impact:** More review cycles than other stories
- **Learning:** Delete operations have inherent complexity (confirmation flow, idempotency, double-click prevention) that should be explicitly specified upfront

### Flashing/Logout Issue (Story 2.2)
- **Issue:** Brief UI flash before 401 redirect when token was invalid/expired
- **Impact:** Minor UX issue caught during development
- **Resolution:** Improved auth error handling in `useLogout` hook
- **Learning:** Auth error handling should be standardized early and applied consistently across all protected API calls
