## Challenges & Learnings

### Scope Creep (Story 1.2)
- **Issue:** Story 1.2 (Login) implemented parts of Story 1.3's backend (logout endpoint, refresh tokens)
- **Impact:** Story 1.3 became frontend-only
- **Learning:** Define story scope more precisely upfront; document what belongs to which story

### Missing localStorage Key (Hotfix Required)
- **Issue:** `user_email` was read in Dashboard but never stored during login
- **Impact:** Required a hotfix branch (`fix/dashboard-email-display`)
- **Learning:** Ensure all localStorage keys are documented in story specs; add to acceptance criteria checklist

### Minor Technical Debt
- FastAPI `on_event` deprecation warnings in test logs
- SQLite connection warnings (non-blocking)
